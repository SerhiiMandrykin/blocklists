## Summary

Add malicious domains from CERT-UA#6318437 ("Вектори первинної компрометації UAC-0145 станом на липень 2026 року" — UAC-0145 initial compromise vectors as of July 2026).

| Field | Details |
|-------|---------|
| **Threat actor** | UAC-0145 (subcluster of UAC-0002 — Sandworm, APT44, Seashell Blizzard) |
| **Campaign** | Initial access via trojanized torrent installers, Signal-delivered fake "antivirus" tools, and ClickFix fake-CAPTCHA pages that trick users into running PowerShell commands. Payloads include GHETTOVIBE, SCOUTCURL, FLUIDLEECH, LOADLOOP, FREAKYPOLL, SMARTAXE and the Android backdoor COWARDDUCK. |
| **Domains added** | 10 |
| **Source** | https://cert.gov.ua/article/6318437 |

## Domains to block

- `update-requirements.com` — FREAKYPOLL (Python backdoor) C2
- `entouchnetworks.com` — SMARTAXE (ClickFix content-swap script) infrastructure
- `smartlinkupload.com` — attacker infrastructure (covers `delta.smartlinkupload.com` via subdomain blocking)
- `diagnostics-monitoring.com` — GHETTOVIBE distribution (`static.` subdomain observed; root blocked as attacker-controlled)
- `opennetworkconnect.com` — GHETTOVIBE distribution (`static.` subdomain observed; root blocked as attacker-controlled)
- `softupdater.org` — FLUIDLEECH loader infrastructure
- `softchecker.org` — FLUIDLEECH loader infrastructure (`soft.` subdomain observed; root blocked as attacker-controlled)
- `softpacker.org` — FLUIDLEECH loader infrastructure (`pack.` subdomain observed; root blocked as attacker-controlled)
- `offlce366.com` — typosquat of Microsoft Office 365, attacker infrastructure
- `365softupdate.com` — fake Microsoft update infrastructure

## Excluded (legitimate services abused by attackers)

- `images.stockmemory.site` — explicitly marked by CERT-UA as a legitimate resource abused as COWARDDUCK C2 (commands/data hidden in hosted images)
- `images.stockmemory.space` — same as above
- `proxy.duckduckgo.com` — legitimate DuckDuckGo image proxy used by COWARDDUCK for C2 communication
- `steamcommunity.com` — legitimate Steam community platform abused for command/data retrieval

## Notes

- UAC-0145 uses the ClickFix technique: compromised websites serve a fake CAPTCHA (via the Cloaking.House service and the SMARTAXE script) instructing victims to paste a PowerShell command into a terminal, which drops a VBS payload (GHETTOVIBE) into the Startup folder.
- SMARTAXE resolves its C2 domain dynamically from an Ethereum smart contract (`eth_call`), so blocking the currently known domains may not be exhaustive — expect rotation.
- Remote access is maintained via legitimate OpenSSH and TOR port forwarding (ports 445, 3389, 22); the Android backdoor COWARDDUCK exfiltrates files via the Dropbox API.
- Recommend monitoring for `Copilot Agent.vbs` in Startup folders and `%LOCALAPPDATA%\SystemHelper\python\` as host-based indicators.
