## Notes

- The fake Cloudflare page domain and script mode (0 inactive / 1 passive tracking / 2 show ClickFix) are stored in a Polygon or Ethereum smart contract, letting the actor rotate domains centrally without re-accessing the compromised sites. Expect new domains to appear; the TDS path `/tds/tds.php` is a useful hunting pattern.
- Three MSI variants were observed: direct LUNEXSTEALER install; a loader with UAC bypass, Defender exclusions and BYOVD via vulnerable AMD `PDFWKRNL.sys` (CVE-2023-20598); and DLL side-loading via legitimate `FnHotkeyUtility.exe` loading malicious `spkvol.dll`.
- LUNARAXE extension masquerades as "Microsoft Office Word Editor", steals cookies/history/form credentials, strips CSP headers, and gives remote browser control; NAIVEMESS (`com.lunex.explorer` native-messaging host) adds file system access.
- C2 over HTTP and WebSocket also uses bare IPs (107.175.82.242, 193.178.158.61, 193.178.159.128, 109.238.86.112/113, 176.53.159.40, 159.69.234.218) which cannot be blocked at the DNS level; block them at the firewall.
- Recommendations from CERT-UA: disable Win+R for standard users via GPO, restrict non-admin MSI installs and monitor `msiexec.exe` with a URL argument, enable the Microsoft Vulnerable Driver Blocklist, and allowlist browser extensions.
